# 贴地线设计 · 02 折线预处理与加密

> 输入 lon/lat 折线 → 输出沿地表的密集点三件套（`bottomPositions[]` / `topPositions[]` / `cartographics[]`）。对齐 Cesium `GroundPolylineGeometry.createGeometry` 的前半段（拆段 + cartographic 化 + 去重）与 `interpolateSegment`。文件：`line/line-preprocess.ts`、`line/line-densify.ts`。

---

## 1. 阶段总览

```
options.points (LonLatPoint[]) + arcType + loop + granularity + minHeight + maxHeight
        │ line-preprocess.ts
        ▼
1.1 归一：lon/lat → ECEF Vector3[]（cartographicToCartesian, height=0）
1.2 本初子午线 + IDL 拆段：在 XZ 平面处插入交点（防大几何被 IDL/子午线平面切坏）
1.3 cartographic 化 + 去重（EPSILON12）→ cartographics: Cartographic[]
   （< 2 点则抛 GeoForgeError('LINE_DEGENERATE')）
        │ line-densify.ts
        ▼
1.4 逐段按 arcType 加密（geodesic/rhumb/none），等距插值
   产出（堆数组，扁平 Float64 / number[]）：
     bottomPositionsArray  每点在 minHeight=WALL_INITIAL_MIN_HEIGHT(0) 的 ECEF
     topPositionsArray     每点在 maxHeight=WALL_INITIAL_MAX_HEIGHT(1000) 的 ECEF
     cartographicsArray    每点 [lat, lon]（注意顺序：纬度在前）
   （法线 normalsArray 在 doc 03 同循环内填充）
```

> 高度此处固定用 `WALL_INITIAL_MIN_HEIGHT=0` / `WALL_INITIAL_MAX_HEIGHT=1000`；真实窗口 `[minimumHeight, maximumHeight]` 由 doc 04 `adjustHeights` 在造 box 时再推到位（与 Cesium 完全一致：先建标准墙，后调高度）。

### 2.2 本初子午线 + IDL 拆段（关键，不可省）

Cesium 在两点之间若跨越 `XZ_PLANE`（法线 = `UNIT_Y` = (0,1,0)，即经度 0°/180° 所在平面）就插入交点。**目的**：极大几何穿越 IDL 或本初子午线时，2D 投影与去重会出问题；预先在平面处打点，使每段都落在平面一侧。即便 3D-only 也保留——它同时修复 3D 下跨 IDL 段的法线/插值数值稳定性。

```typescript
const XZ_PLANE = { normal: new Vector3(0, 1, 0), distance: 0 }; // 过原点

function splitAcrossXZPlane(positions: Vector3[], arcType: ArcType): Vector3[] {
  const out: Vector3[] = [positions[0]];
  for (let i = 0; i < positions.length - 1; i++) {
    const p0 = positions[i], p1 = positions[i + 1];
    const x = lineSegmentPlaneIntersection(p0, p1, XZ_PLANE); // 见 §2.3
    if (x !== undefined
        && !p0.equalsEpsilon?.(x, EPSILON7) && distance(x,p0)>EPSILON7
        && distance(x,p1)>EPSILON7) {
      if (arcType === ArcType.GEODESIC) {
        out.push(x.clone());
      } else if (arcType === ArcType.RHUMB) {
        // 用 EllipsoidRhumbLine.findIntersectionWithLongitude 在恒向线上求交点经度处的点
        const lonX = cartesianToCartographic(x, scratchCarto).longitude;
        const rl = new EllipsoidRhumbLine(
          cartesianToCartographic(p0, sc0), cartesianToCartographic(p1, sc1));
        const cx = rl.findIntersectionWithLongitude(lonX, scratchCarto2);
        const xr = cartographicToCartesian(cx, scratchVec);
        if (xr && distance(xr,p0)>EPSILON7 && distance(xr,p1)>EPSILON7) out.push(xr.clone());
      }
      // ArcType.NONE：直连，无需拆（直线本身不跨曲面）；但仍可按 GEODESIC 规则插点保持稳健
    }
    out.push(p1);
  }
  return out;
}
```

### 2.3 线段-平面求交（`lineSegmentPlaneIntersection`）

```typescript
/** Hessian 平面 (normal, distance)。返回 p0→p1 与平面的交点，无交（含端点贴面）返回 undefined。 */
function lineSegmentPlaneIntersection(p0: Vector3, p1: Vector3, plane): Vector3 | undefined {
  const dir = new Vector3().subVectors(p1, p0);
  const denom = plane.normal.dot(dir);
  if (Math.abs(denom) < EPSILON_DENOM) return undefined;       // 平行
  const t = -(plane.normal.dot(p0) + plane.distance) / denom;
  if (t < 0 || t > 1) return undefined;                        // 交点在段外
  return new Vector3().copy(dir).multiplyScalar(t).add(p0);
}
```

### 2.4 cartographic 化 + 去重（输出端）

```typescript
function toCartographicsDedup(splitPositions: Vector3[]): Cartographic[] {
  const cartos = splitPositions.map(p => {
    const c = cartesianToCartographic(p, createCartographic(0,0,0))!;
    c.height = 0; return c;
  });
  // 相邻 Cartographic.equalsEpsilon(EPSILON12) 去重（lon/lat 各比）
  const deduped = removeDuplicateCartographics(cartos, EPSILON12);
  if (deduped.length < 2) throw new GeoForgeError('LINE_DEGENERATE');
  return deduped;
}
```

> `Cartographic.equalsEpsilon(EPSILON12)`：`|lon1-lon2| ≤ ε && |lat1-lat2| ≤ ε`（绝对容差）。等价 Cesium `arrayRemoveDuplicates(cartographics, Cartographic.equalsEpsilon)`。

## 3. `line-densify.ts` —— 逐段加密（核心）

输出三个扁平数组 + 一个 `normalsArray`（法线在 doc 03 主循环里填，但加密点的法线在加密时一并写入）。加密只负责 bottom/top/cartographic；端点的几何法线由 doc 03 负责。两者在同一主循环里交替进行，因此 `line-densify.ts` 导出**单点构造**与**单段插值**两个原子函数，主循环（在 doc 03 §3）调用它们。

### 3.1 单段插值 `interpolateSegment`（逐字对齐 Cesium）

```typescript
/**
 * 在 start→end 之间按 granularity 等弧长插入「中间点」（不含 start/end 本身），
 * 把每个中间点的 bottom(@minHeight)、top(@maxHeight)、右向法线、cartographic
 * 追加到四个数组。granularity 为弧度角分辨率，先转为弧长阈值比较。
 */
export function interpolateSegment(
  start: Cartographic, end: Cartographic,
  minHeight: number, maxHeight: number,
  granularity: number, arcType: ArcType,
  normalsArray: number[], bottomPositionsArray: number[],
  topPositionsArray: number[], cartographicsArray: number[],
): void {
  if (granularity === 0.0) return;

  let line: EllipsoidGeodesic | EllipsoidRhumbLine;
  if (arcType === ArcType.GEODESIC) line = new EllipsoidGeodesic(start, end);
  else if (arcType === ArcType.RHUMB) line = new EllipsoidRhumbLine(start, end);
  else /* NONE */ { interpolateChord(start, end, minHeight, maxHeight,
                      granularity, normalsArray, bottomPositionsArray,
                      topPositionsArray, cartographicsArray); return; }

  const surfaceDistance = line.surfaceDistance;
  if (surfaceDistance < granularity) return;   // 段太短，无需中间点

  // 该段所有中间点共用同一「右向法线」（端点右法线，doc 03 §computeRightNormal）
  const interpolatedNormal = computeRightNormal(start, end, maxHeight, scratchNormal);

  const segments = Math.ceil(surfaceDistance / granularity);
  const interpointDistance = surfaceDistance / segments;
  let distanceFromStart = interpointDistance;
  const pointsToAdd = segments - 1;
  for (let i = 0; i < pointsToAdd; i++) {
    const c = line.interpolateUsingSurfaceDistance(distanceFromStart, scratchCarto);
    const b = getPosition(c, minHeight, scratchBottom);
    const t = getPosition(c, maxHeight, scratchTop);
    pack3(interpolatedNormal, normalsArray);   // 追加 3 个分量
    pack3(b, bottomPositionsArray);
    pack3(t, topPositionsArray);
    cartographicsArray.push(c.latitude, c.longitude);   // 注意：lat 在前
    distanceFromStart += interpointDistance;
  }
}
```

> 这里 `granularity` 与 surfaceDistance 同单位比较是 Cesium 的实现细节：`granularity` 名义是角分辨率（弧度），但 `interpolateSegment` 直接拿它和「米」比。Cesium `GroundPolylineGeometry` 默认 granularity 来自 `RADIANS_PER_DEGREE * ...`，实际作为「每隔约这么多（米/弧度混用）插一点」的密度旋钮，逐字保留即可（不要擅自换算成弧长，否则与 Cesium 行为不一致）。本项目沿用 `LINE_DEFAULT_GRANULARITY = π/180/32`。

### 3.2 `ArcType.NONE` 的弦插值 `interpolateChord`

直线段在 ECEF 上等距插值，每点投到地表（`scaleToGeodeticHeight`）后取 bottom/top：

```typescript
function interpolateChord(start, end, minHeight, maxHeight, granularity,
  normalsArray, bottomPositionsArray, topPositionsArray, cartographicsArray): void {
  const startEcef = getPosition(start, 0, scratchA);
  const endEcef   = getPosition(end,   0, scratchB);
  const dist = startEcef.distanceTo(endEcef);
  if (dist < granularity) return;
  const interpolatedNormal = computeRightNormal(start, end, maxHeight, scratchNormal);
  const segments = Math.ceil(dist / granularity);
  for (let i = 1; i < segments; i++) {
    const t = i / segments;
    const ecef = scratchC.copy(startEcef).lerp(endEcef, t);     // 弦上点
    const c = cartesianToCartographic(ecef, scratchCarto)!;     // 反投影回 lon/lat
    pack3(interpolatedNormal, normalsArray);
    pack3(getPosition(c, minHeight, scratchBottom), bottomPositionsArray);
    pack3(getPosition(c, maxHeight, scratchTop), topPositionsArray);
    cartographicsArray.push(c.latitude, c.longitude);
  }
}
```

## 5. 边界与精度（本篇范围）

1. **去重两道**：输入端 ECEF 距离去重（EPSILON7）、cartographic 端 lon/lat 去重（EPSILON12）。零长度段会让后续 `forward = normalize(0)` 产生 NaN，必须挡住。
2. **< 2 点**：抛 `GeoForgeError('LINE_DEGENERATE')`，不静默返回空几何。
3. **loop**：`loop && pointCount===2` 时强制 `loop=false`（两点无法成环），与 Cesium 一致；拆段/去重在 loop 判定之前完成。
4. **granularity ≤ 0**：`interpolateSegment` 直接 return（不插中间点），仅保留折点。校验阶段应把 `granularity` clamp 到 `(0, LINE_DEFAULT_GRANULARITY*N]` 合理上限，避免 0 导致长段穿地。
5. **跨对跖**：靠 §2.2 的 XZ 平面拆段把超大段切碎；任何单段都不应接近对跖，从而绕过 Vincenty 不收敛区。
