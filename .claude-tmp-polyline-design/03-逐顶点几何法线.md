# 贴地线设计 · 03 逐顶点几何法线

> 为密集线的每个顶点计算「几何法线」（miter 方向）。这些法线决定 doc 04 每段 box 的 start/end 斜接平面朝向，进而决定拐角处线宽是否连续、不漏不叠。文件：`line/line-geometry-normals.ts`。逐字对齐 Cesium `computeVertexMiterNormal` / `computeRightNormal` / `tangentDirection` / `breakMiter` 与 `createGeometry` 的墙构建主循环。

---

## 1. 概念

- **几何法线（geometry normal）**：每个顶点处、位于「该点上方向 up 的切平面内」、指向线**局部右侧**的单位向量。它不是椭球面法线，而是「线的横向方向」。
- 内部顶点：法线 = 相邻两段方向的**角平分线方向的右法线**（miter，斜接）。拐角越尖，斜接 box 越长（VS/FS 用平面距离裁切，过尖时由 `breakMiter` 打断）。
- 端点（非 loop）：法线 = `normalize(cross(forward, up))`（垂直于首/末段）。
- loop：首尾顶点都按内部顶点（miter）处理，且首点法线是末点 miter 的镜像（见 §4）。

约定常量（doc 00 §5）：

```
cosine90  = 0.0
cosine180 = -1.0
MITER_BREAK_SMALL = cos(30°)  ≈  0.8660254037844387
MITER_BREAK_LARGE = cos(150°) ≈ -0.8660254037844387
EPSILON5 = 1e-5
```

## 2. 原子函数

### 2.1 `direction`（doc 01 §5，复用）

`out = normalize(target - origin)`。

### 2.2 `tangentDirection` —— 把邻点方向正交化到 up 切平面

```typescript
/**
 * 返回从 origin 指向 target、但被正交化到「以 up 为法线的切平面」内的单位向量。
 * 即去掉沿 up 的分量后归一。用于 miter 角平分，避免高差污染横向方向。
 */
function tangentDirection(target: Vector3, origin: Vector3, up: Vector3, out: Vector3): Vector3 {
  direction(target, origin, out);          // out = normalize(target-origin)
  out.cross(up).normalize();                // out = normalize(out × up)
  out.copy(up).cross(out0).normalize();     // out = normalize(up × (out×up))  —— 见下注
  return out;
}
```

> 实现细节（逐字对齐 Cesium，注意叉乘顺序）：
> ```
> result = normalize(target - origin)
> result = normalize(result × up)          // 临时：与 up 正交的「侧向」
> result = normalize(up × result)          // 再与 up 正交得到「切平面内、指向 target 的投影方向」
> ```
> Three.js `Vector3.cross` 是 in-place `this = this × v`，第二步需要 `up × result`，故用 scratch：`scratch.copy(up).cross(result)` 后赋回 `result`。务必保证最终是 `up × result` 而非 `result × up`（符号相反）。

### 2.3 `computeRightNormal` —— 端点右法线

```typescript
/** 端点（非 loop 首/末点）法线：垂直于该段、指向右侧。 */
function computeRightNormal(start: Cartographic, end: Cartographic,
                            maxHeight: number, out: Vector3): Vector3 {
  const startBottom = getPosition(start, 0.0, sA);
  const startTop    = getPosition(start, maxHeight, sB);
  const endBottom   = getPosition(end,   0.0, sC);
  const up      = direction(startTop, startBottom, sB);  // 复用 sB
  const forward = direction(endBottom, startBottom, sC); // 复用 sC
  out.copy(forward).cross(up).normalize();               // out = normalize(forward × up)
  return out;
}
```

### 2.4 `computeVertexMiterNormal` —— 内部顶点斜接法线

```typescript
/**
 * 内部顶点的 miter 法线：相邻两段方向（切平面内）的角平分线对应的右法线。
 * @param previousBottom 前一顶点 @minHeight
 * @param vertexBottom   当前顶点 @minHeight
 * @param vertexTop      当前顶点 @maxHeight（定义 up）
 * @param nextBottom     后一顶点 @minHeight
 */
function computeVertexMiterNormal(previousBottom: Vector3, vertexBottom: Vector3,
  vertexTop: Vector3, nextBottom: Vector3, out: Vector3): Vector3 {
  const up = direction(vertexTop, vertexBottom, sUp);              // 当前点「上」
  const toPrevious = tangentDirection(previousBottom, vertexBottom, up, sPrev); // 切平面内指向前点
  const toNext     = tangentDirection(nextBottom,     vertexBottom, up, sNext); // 切平面内指向后点

  // 特例：前后切向几乎反向（直线穿过，dot≈-1）→ 无需斜接，取与 up、toPrevious 垂直的法线
  if (equalsEpsilon(toPrevious.dot(toNext), cosine180, EPSILON5)) {
    out.copy(up).cross(toPrevious).normalize();   // normalize(up × toPrevious)
    return out;
  }
  // 一般情形：角平分 = toNext + toPrevious，归一
  out.copy(toNext).add(toPrevious).normalize();
  // 翻转校正：若得到的法线让 forward 指向「偏后方」，取反，保证朝右
  const forward = sFwd.copy(up).cross(out);        // forward = up × out
  if (toNext.dot(forward) < cosine90) out.negate();
  return out;
}
```

> 数学含义：`out` 是平分前后切向夹角的方向（即拐角对称轴），`up × out` 给出该顶点的「前向」。若前向与 `toNext` 反向（点积 < 0）说明法线指错半边，取反。

### 2.5 `breakMiter` —— 过尖拐角打断斜接

```typescript
/**
 * 若 endGeometryNormal 与本段方向夹角过小/过大（拐角过尖），把法线绕 up 旋 ±90°
 * 打断斜接，防止 box 退化/暴长。原地修改 endGeometryNormal，返回是否打断。
 */
function breakMiter(endGeometryNormal: Vector3, startBottom: Vector3,
                    endBottom: Vector3, endTop: Vector3): boolean {
  const lineDirection = direction(endBottom, startBottom, sLine);
  const dot = lineDirection.dot(endGeometryNormal);
  if (dot > MITER_BREAK_SMALL || dot < MITER_BREAK_LARGE) {
    const vertexUp = direction(endTop, endBottom, sUp);
    const angle = dot < MITER_BREAK_LARGE ? Math.PI / 2 : -Math.PI / 2;
    // 绕 vertexUp 旋 angle（四元数）后原地写回 endGeometryNormal
    const q = quaternionFromAxisAngle(vertexUp, angle, sQuat);
    applyQuaternion(endGeometryNormal, q);   // endGeometryNormal = q · endGeometryNormal
    return true;
  }
  return false;
}
```

> `quaternionFromAxisAngle` + `applyQuaternion`：用 Three.js `Quaternion.setFromAxisAngle(axis, angle)` 与 `Vector3.applyQuaternion`。逐字对齐 Cesium `Quaternion.fromAxisAngle` + `Matrix3.fromQuaternion` + `multiplyByVector`（结果等价，用四元数直乘更省）。

## 3. 墙构建主循环（在 `line-geometry-normals.ts` 或 `line-densify.ts` 编排）

把 doc 02 的加密原子函数（`interpolateSegment` / `pushVertex`）与本篇法线函数串成一遍遍历，产出完整 `DensifiedLine`（含 `normalsArray`）。逐字对齐 Cesium `createGeometry` 第二半段：

```typescript
export function buildWallArrays(cartographics: Cartographic[], loop: boolean,
  arcType: ArcType, granularity: number,
  minHeight = WALL_INITIAL_MIN_HEIGHT, maxHeight = WALL_INITIAL_MAX_HEIGHT): DensifiedLine {

  const N = cartographics.length;
  const normalsArray: number[] = [], bottomPositionsArray: number[] = [],
        topPositionsArray: number[] = [], cartographicsArray: number[] = [];

  // ── 首点 ──
  const start = cartographics[0], next = cartographics[1], preStart = cartographics[N - 1];
  const previousBottom = getPosition(preStart, minHeight, sPrevB);
  const nextBottom     = getPosition(next,     minHeight, sNextB);
  const vertexBottom   = getPosition(start,    minHeight, sVB);
  const vertexTop      = getPosition(start,    maxHeight, sVT);
  const vertexNormal   = new Vector3();
  if (loop) computeVertexMiterNormal(previousBottom, vertexBottom, vertexTop, nextBottom, vertexNormal);
  else      computeRightNormal(start, next, maxHeight, vertexNormal);
  pack3(vertexNormal, normalsArray);
  pack3(vertexBottom, bottomPositionsArray);
  pack3(vertexTop, topPositionsArray);
  cartographicsArray.push(start.latitude, start.longitude);
  interpolateSegment(start, next, minHeight, maxHeight, granularity, arcType,
                     normalsArray, bottomPositionsArray, topPositionsArray, cartographicsArray);

  // ── 中间点 i = 1 .. N-2 ──
  let pBottom = vertexBottom.clone(), vBottom = nextBottom.clone();
  for (let i = 1; i < N - 1; i++) {
    pBottom.copy(vBottom_prevSlot);          // previousBottom = 上一 vertexBottom
    vBottom.copy(nextBottom_prevSlot);       // vertexBottom   = 上一 nextBottom
    const vCarto = cartographics[i];
    getPosition(vCarto, maxHeight, vertexTop);
    getPosition(cartographics[i + 1], minHeight, nextBottom);
    computeVertexMiterNormal(pBottom, vBottom, vertexTop, nextBottom, vertexNormal);
    pack3(vertexNormal, normalsArray);
    pack3(vBottom, bottomPositionsArray);
    pack3(vertexTop, topPositionsArray);
    cartographicsArray.push(vCarto.latitude, vCarto.longitude);
    interpolateSegment(cartographics[i], cartographics[i + 1], minHeight, maxHeight,
                       granularity, arcType, normalsArray, bottomPositionsArray,
                       topPositionsArray, cartographicsArray);
  }

  // ── 末点 ──
  const endC = cartographics[N - 1], preEndC = cartographics[N - 2];
  getPosition(endC, minHeight, vertexBottom);
  getPosition(endC, maxHeight, vertexTop);
  if (loop) {
    const postEnd = getPosition(cartographics[0], minHeight, sNextB);
    const preEnd  = getPosition(preEndC, minHeight, sPrevB);
    computeVertexMiterNormal(preEnd, vertexBottom, vertexTop, postEnd, vertexNormal);
  } else {
    computeRightNormal(preEndC, endC, maxHeight, vertexNormal);
  }
  pack3(vertexNormal, normalsArray);
  pack3(vertexBottom, bottomPositionsArray);
  pack3(vertexTop, topPositionsArray);
  cartographicsArray.push(endC.latitude, endC.longitude);

  // ── loop 闭合：补末→首段，并把首点数据复制到尾（首尾相接）──
  if (loop) {
    interpolateSegment(endC, start, minHeight, maxHeight, granularity, arcType,
                       normalsArray, bottomPositionsArray, topPositionsArray, cartographicsArray);
    // 末尾再放一份首点（法线/bottom/top 复制 index 0..2），cartographic 同理
    appendCopyOfFirst(normalsArray, bottomPositionsArray, topPositionsArray);
    cartographicsArray.push(start.latitude, start.longitude);
  }

  return { normalsArray, bottomPositionsArray, topPositionsArray, cartographicsArray,
           loop, pointCount: bottomPositionsArray.length / 3 };
}
```

> 上面 `vBottom_prevSlot` / `nextBottom_prevSlot` 表示 Cesium 用 `Cartesian3.clone` 在 scratch 间倒手（`previousBottom = vertexBottom; vertexBottom = nextBottom`）。实现时用三个固定 scratch `Vector3` 轮转即可，**勿每点 new**（零 GC，与项目其它几何一致）。

## 4. loop 端点的「镜像」处理（doc 04 也会用到）

Cesium 在生成段属性时，对 loop 还要处理首点法线相对末点 miter 的反向（`generateGeometryAttributes` 开头的 `if (loop) { if (breakMiter(...)) endGeometryNormal = negate }`）。本设计把这一步留到 doc 04 §段循环开头处理（因为它依赖段循环里的 `breakMiter` 状态机），此处只需保证：**loop 时首点与末点用同一 cartographic 的 miter 法线，且尾部复制了首点三件套**，使段循环能首尾相接。

---

## 5. 边界与精度

1. **直线穿过点（dot≈-1）**：`computeVertexMiterNormal` 特例分支返回 `up × toPrevious`，避免角平分退化为零向量。
2. **退化 up**：`up = normalize(top - bottom)`；因 top/bottom 高差恒为 1000m（WALL 初值），`up` 永不为零。
3. **scratch 轮转**：previous/vertex/next bottom 三槽轮转，禁止误用同一 scratch 导致数据被覆盖（Cesium 用独立 scratch，移植时逐一对应命名）。
4. **法线单位化**：所有输出法线必须 `normalize`；下游 VS 用 `czm_normal *` 变换后还会再 normalize，但 CPU 端不归一会让 `breakMiter` 的 dot 判据失真。
