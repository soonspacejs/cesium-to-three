# 贴地线设计 · 07 材质与渲染状态

> 定义 `materials.ts` 的改动：① 注入 `czm_metersPerPixel` 及其依赖到 VS/FS prefix；② 新增 `czm_projection`、`czm_pixelRatio`、`u_lineWidth*`、虚线等 uniform 声明；③ `createPolylineMaterial` 工厂（单 mesh、BackSide、无 stencil、深度测试关、预乘混合）。逐字对齐 Cesium `GroundPolylinePrimitive` 的 `getRenderState(mask3DTiles=false)`（地形分类，本项目场景）。

---

## 1. 渲染状态对照（贴地线 vs polygon colorMesh）

| 项 | polygon colorMesh（`createColorMaterial`） | **polyline（`createPolylineMaterial`）** | 依据 |
|---|---|---|---|
| `glslVersion` | GLSL3 | GLSL3 | WebGL2 / GLSL ES 3.00 |
| `side` | `DoubleSide` | **`BackSide`** | Cesium `cull.enabled=true` + 反绕几何 = 画背面；相机进盒仍覆盖 |
| `colorWrite` | true | true | 着色 |
| `depthWrite` | false | false | Cesium `depthMask:false` |
| `depthTest` | **false** | **false** | 地形比对在 FS 手动做（采样深度纹理重建），硬件 depthTest 关；Cesium 地形分类 RS 无 depthTest 项 |
| `stencilWrite` | true（NotEqual/Zero 清） | **false** | ★ 与 polygon 最大区别：贴地线不碰模板缓冲 |
| `transparent` | true | true | 半透混合 |
| `blending` | Custom（Add） | Custom（Add） | 预乘 alpha |
| `blendSrc/Dst` | ONE / ONE_MINUS_SRC_ALPHA | ONE / ONE_MINUS_SRC_ALPHA | 预乘 |
| `blendSrcAlpha/DstAlpha` | ONE / ONE_MINUS_SRC_ALPHA | ONE / ONE_MINUS_SRC_ALPHA | 预乘 |
| pass 数 | 3（front/back stencil + color） | **1**（仅 color） | 深度重建法无需 stencil |

> **BackSide 理由**：doc 04 的 `REFERENCE_INDICES` 与 8 顶点顺序产生「反绕」盒子。Cesium 用 `cull.enabled` 剔正面、画背面，目的是「防双绘 + 相机进入盒子内部时背面仍渲染、保证 FS 在所有被覆盖像素跑到」。Three.js 中 `side: BackSide`（渲染背面、剔除正面）等价。**勿用 DoubleSide**：会双绘同一像素，预乘混合下颜色翻倍/边缘发暗。

> **depthTest=false 理由**：贴地线的「深度比对」在 FS 内通过采样 `czm_globeDepthTexture` 重建地形点完成（doc 06 §3-7），与硬件深度测试无关。盒子本身（挤出体）的深度不应参与裁剪——若开 depthTest，盒子可能被地形/其它物体的硬件深度挡掉，导致线缺失。故关闭硬件 depthTest，由 FS 全权裁切。

## 2. `materials.ts` prefix 改动

### 2.1 顶部新增 import

```typescript
import cesiumMetersPerPixel from '../../../cesium-ground-source/engine/Source/Shaders/Builtin/Functions/metersPerPixel.glsl?raw';
```

### 2.2 `createVertexPrefix` 追加（VS 也用 metersPerPixel）

在 `createVertexPrefix` 现有 uniform 之后追加：

```glsl
// ── 贴地线 VS 专用（其它材质不声明这些 in/uniform 也无害，因 POLYLINE_VS 才用）──
uniform mat4  czm_projection;           // 纯投影矩阵（Float64 每帧写入）—— 线 VS 先挤出再投影
uniform vec4  czm_viewport;             // (0,0,w,h)  metersPerPixel 依赖
uniform vec4  czm_frustumPlanes;        // (top,bottom,left,right) metersPerPixel 依赖
uniform float czm_pixelRatio;           // = renderer.getPixelRatio()
#define czm_orthographicIn3D 0.0        // 透视恒 0（避免 uniform）
uniform float u_lineWidthPixels;
uniform float u_lineWidthMode;          // 0=screen,1=world
uniform float u_lineWidthMeters;
#define GLOBE_MINIMUM_ALTITUDE 55000.0

const float czm_pi = 3.141592653589793; // metersPerPixel 不需要，但保持与 FS 对齐
${ cesiumMetersPerPixel }
```

> 注意：`czm_viewport` / `czm_frustumPlanes` 在 stencil VS 不存在（VS prefix 原本只有 FS 那份有），需在 VS prefix 显式加。`czm_currentFrustum` / `czm_sceneMode` VS prefix 已有（metersPerPixel 依赖）。这些 uniform 对非贴地线材质只是多声明、不使用，WebGL 会因未用而被 GLSL 编译器优化掉或保留为 inactive uniform，**对 stencil/color 材质零行为影响**（与项目既有「u_circle*/u_polygon* 出现在所有材质 prefix 但仅部分使用」的模式一致）。

### 2.3 `createFragmentPrefix` 追加

在现有 uniform 之后追加：

```glsl
uniform vec4  czm_viewport;             // 已有；metersPerPixel 复用
uniform vec4  czm_frustumPlanes;        // 已有
uniform float czm_pixelRatio;           // 新增
#define czm_orthographicIn3D 0.0
uniform float u_lineWidthMode;
uniform float u_lineWidthMeters;
uniform float u_lineDashEnabled;
uniform float u_lineDashLengthMeters;
uniform float u_lineGapLengthMeters;
uniform float u_lineTotalMeters;
${ cesiumMetersPerPixel }              // 在 czm_pi 等常量之后（metersPerPixel 不依赖 czm_pi）
```

> `czm_sceneMode` 在 FS prefix 原本可能未声明（stencil FS 不用）——metersPerPixel 依赖它，需确认 FS prefix 含 `uniform float czm_sceneMode;`，否则补上。

## 3. `createPolylineMaterial` 工厂

```typescript
/**
 * 贴地线单 pass 材质：BackSide、depthTest/Write 关、无 stencil、预乘混合。
 * 与 createColorMaterial 共用 createVertexPrefix/createFragmentPrefix（含全部 czm builtin
 * + log-depth helper），仅替换 shader 主体为 POLYLINE_VS/FS，并调整渲染状态。
 *
 * @param uniforms 共享 uniform 映射（createSharedUniforms 产出，doc 08）。须含
 *                 u_lineWidthPixels / u_lineWidthMode / u_lineWidthMeters / czm_projection /
 *                 czm_pixelRatio / 虚线 uniform 等。
 */
export function createPolylineMaterial(uniforms: SharedUniforms): RawShaderMaterial {
  const defines = ENABLE_LOG_DEPTH ? ['LOG_DEPTH', 'PER_INSTANCE_COLOR'] : ['PER_INSTANCE_COLOR'];

  const material = new RawShaderMaterial({
    glslVersion: GLSL3,
    uniforms,
    vertexShader:   createVertexPrefix(defines)   + POLYLINE_VS,
    fragmentShader: createFragmentPrefix(defines) + POLYLINE_FS,
    side: BackSide,            // Cesium：反绕几何画背面
    transparent: true,
    colorWrite: true,
    depthWrite: false,         // depthMask:false
    depthTest: false,          // 地形比对在 FS（采样深度纹理）
    stencilWrite: false,       // ← 不碰模板缓冲
    blending: CustomBlending,
    blendEquation: AddEquation,
    blendSrc: OneFactor, blendDst: OneMinusSrcAlphaFactor,         // 预乘 alpha
    blendSrcAlpha: OneFactor, blendDstAlpha: OneMinusSrcAlphaFactor,
  });
  return material;
}
```

> `PER_INSTANCE_COLOR` define 走纯色路径（doc 06 §9a）；要启用虚线/材质，去掉该 define 并设 `u_lineDashEnabled=1`（doc 06 §4）。两条路径都在 shader 里实现，define 只切分支，无运行时开销。

### 3.1 需 import 的 Three 枚举（materials.ts 已部分含）

`BackSide`、`CustomBlending`、`AddEquation`、`OneFactor`、`OneMinusSrcAlphaFactor`、`RawShaderMaterial`、`GLSL3`。`BackSide` 需新增 import（现有文件用 `DoubleSide`）。

## 4. 与全局地形深度纹理的关系（复用，零改动）

贴地线 FS 采样的 `czm_globeDepthTexture` 由 `depth.ts::CesiumGlobeDepth` + `createPackDepthMaterial` 产出——这是 polygon 描边已在用的全局深度 pass：把地形/瓦片（或无瓦片时的 `EllipsoidDepthMesh` 兜底椭球面）渲染到深度纹理。贴地线**不新增任何深度 pass**，只在 `update` 时把同一张 `frameState.depthTexture` 写进自己的 `uniforms.czm_globeDepthTexture`（doc 08）。这保证线与面贴在**同一基准面**上。

---

## 5. 渲染顺序

贴地线单 mesh，`renderOrder` 默认 `LINE_DEFAULT_RENDER_ORDER = 40`（> polygon 的 30），使线压在贴地面之上。无 stencil 块内偏移（polygon 用 +1/+2 给 back-stencil/color），线就一个数。`setRenderOrder(n)` 直接设 mesh.renderOrder（doc 08）。

---

## 6. 边界与精度

1. **inactive uniform**：新增的 czm_viewport/frustumPlanes/pixelRatio 等出现在所有材质 prefix；非贴地线材质不使用，GLSL 编译为 inactive，`updateFrameStateUniforms` 写它们时 Three 对 inactive uniform 静默跳过，**不报错、不影响 stencil 路径**。已被项目既有 u_circle*/u_polygon* 模式验证。
2. **BackSide ≠ DoubleSide**：务必 BackSide，理由见 §1。
3. **depthTest 必须 false**：否则盒子被硬件深度挡掉，线缺失。
4. **预乘混合**：blendSrc=ONE 必须配 FS 内 `col.rgb*=col.a`（doc 06 §10）。
5. **czm_sceneMode 在 FS prefix**：metersPerPixel 依赖，确认存在。
