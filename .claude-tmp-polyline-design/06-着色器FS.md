# 贴地线设计 · 06 片元着色器（FS）

> 移植 `Shaders/PolylineShadowVolumeFS.glsl` 到项目约定。FS 是贴地线算法的灵魂：**采样全局地形深度纹理重建当前像素下的地形点(EC)，算该点到线 right/start/end 三平面的距离，超出半宽或越过端面则 discard，否则上色**。常量字符串 `POLYLINE_FS` 放 `materials.ts`，与现有 color shader 共用 `createFragmentPrefix`。

---

## 1. 依赖的 prefix（`createFragmentPrefix` 已提供，doc 07 补一项）

`createFragmentPrefix(defines)` 已注入：`out vec4 out_FragColor`、`czm_globeDepthTexture`、`czm_viewport`、`czm_inverseProjection`、`czm_viewportTransformation`、`czm_frustumPlanes`、`czm_currentFrustum`、log-depth uniforms、`u_color`、`czm_unpackDepth`、`czm_windowToEyeCoordinates`、`czm_planeDistance`、`czm_gammaCorrect`、`czm_writeDepthClamp`、`LOG_DEPTH_FRAGMENT_HELPERS`（`czm_writeLogDepth`）、`czm_branchFreeTernary`。

doc 07 在 FS prefix **补充**：`czm_metersPerPixel`（+ `czm_pixelRatio` / `#define czm_orthographicIn3D 0.0`，`czm_viewport`/`czm_frustumPlanes`/`czm_currentFrustum`/`czm_sceneMode` 已在 FS prefix），以及 `u_lineWidthMode` / `u_lineWidthMeters`（世界宽模式）。

> `czm_windowToEyeCoordinates`（已在 prefix）内部用 `czm_inverseProjection` + `czm_viewportTransformation` 把窗口坐标 + 深度反算回 eye space——这正是 polygon 描边重建地形点用的同一套，贴地线零新增。

## 2. `POLYLINE_FS` 全文（逐行注释）

```glsl
// ── 来自 VS（doc 05 §输出）──
in vec4 v_startPlaneNormalEcAndHalfWidth;     // xyz=startPlaneEC.n, w=halfWidth(像素或米·0.5)
in vec4 v_endPlaneNormalEcAndBatchId;         // xyz=endPlaneEC.n,   w=batchId
in vec4 v_rightPlaneEC;                        // 右平面 (n, w)
in vec4 v_endEcAndStartEcX;                    // xyz=ecEnd, w=ecStart.x
in vec4 v_texcoordNormalizationAndStartEcYZ;   // x=|texNormX|, y=texNormY, zw=ecStart.yz

void main() {
  // 1) 采样全局地形深度纹理（屏幕 UV = gl_FragCoord.xy / viewport.zw）
  float logDepthOrDepth = czm_unpackDepth(
      texture(czm_globeDepthTexture, gl_FragCoord.xy / czm_viewport.zw));
  vec3 ecStart = vec3(v_endEcAndStartEcX.w, v_texcoordNormalizationAndStartEcYZ.zw);

  // 2) 天空（无地形）→ 丢弃
  if (logDepthOrDepth == 0.0) {
#ifdef DEBUG_SHOW_VOLUME
    out_FragColor = vec4(1.0, 0.0, 0.0, 0.5); return;   // 调试：显示盒子
#else
    discard;
#endif
  }

  // 3) 重建当前像素下的「地形点」eye coordinate（关键！）
  vec4 eyeCoordinate = czm_windowToEyeCoordinates(gl_FragCoord.xy, logDepthOrDepth);
  eyeCoordinate /= eyeCoordinate.w;

  // 4) 屏宽：把半宽（像素）换算成该地形点深度下的世界半宽（恒定屏宽的来源）
  float halfMaxWidth = v_startPlaneNormalEcAndHalfWidth.w * czm_metersPerPixel(eyeCoordinate);

  // 5) 地形点到「右平面」的横向距离（决定是否在线宽内）
  float widthwiseDistance = czm_planeDistance(v_rightPlaneEC, eyeCoordinate.xyz);

  // 6) 地形点相对 start/end 斜接平面（决定是否在段长范围内）
  float distanceFromStart = czm_planeDistance(
      v_startPlaneNormalEcAndHalfWidth.xyz, -dot(ecStart, v_startPlaneNormalEcAndHalfWidth.xyz),
      eyeCoordinate.xyz);
  float distanceFromEnd = czm_planeDistance(
      v_endPlaneNormalEcAndBatchId.xyz, -dot(v_endEcAndStartEcX.xyz, v_endPlaneNormalEcAndBatchId.xyz),
      eyeCoordinate.xyz);

  // 7) 裁切：横向超半宽、或越过起/止端面 → 丢弃
  if (abs(widthwiseDistance) > halfMaxWidth || distanceFromStart < 0.0 || distanceFromEnd < 0.0) {
#ifdef DEBUG_SHOW_VOLUME
    out_FragColor = vec4(1.0, 0.0, 0.0, 0.5); return;
#else
    discard;
#endif
  }

  // 8) 沿线纹理坐标 s/t（虚线/箭头/渐变材质用；纯色可忽略 s/t 但仍计算以备扩展）
  //    用「对齐平面」重算 start/end 距离，去斜接畸变（见 §3.2）
  vec3 alignedPlaneNormal;
  alignedPlaneNormal = cross(v_rightPlaneEC.xyz, v_startPlaneNormalEcAndHalfWidth.xyz);
  alignedPlaneNormal = normalize(cross(alignedPlaneNormal, v_rightPlaneEC.xyz));
  distanceFromStart = czm_planeDistance(alignedPlaneNormal, -dot(alignedPlaneNormal, ecStart), eyeCoordinate.xyz);

  alignedPlaneNormal = cross(v_rightPlaneEC.xyz, v_endPlaneNormalEcAndBatchId.xyz);
  alignedPlaneNormal = normalize(cross(alignedPlaneNormal, v_rightPlaneEC.xyz));
  distanceFromEnd = czm_planeDistance(alignedPlaneNormal, -dot(alignedPlaneNormal, v_endEcAndStartEcX.xyz), eyeCoordinate.xyz);

#ifdef PER_INSTANCE_COLOR
  // 9a) 纯色路径（本项目默认）：直接 u_color
  vec4 col = u_color;
#else
  // 9b) 材质路径（虚线/纹理）：s = 沿线归一坐标，t = 横向归一坐标
  float s = clamp(distanceFromStart / (distanceFromStart + distanceFromEnd), 0.0, 1.0);
  s = (s * v_texcoordNormalizationAndStartEcYZ.x) + v_texcoordNormalizationAndStartEcYZ.y;
  float t = (widthwiseDistance + halfMaxWidth) / (2.0 * halfMaxWidth);
  vec4 col = lineMaterial(vec2(s, t));   // 见 §4
#endif

  // 10) 预乘 alpha（与 polygon colorMesh 一致，配合 doc 07 的预乘混合）
  col.rgb *= col.a;
  out_FragColor = col;

  // 11) log-depth（与 VS czm_vertexLogDepth 配对）
  czm_writeLogDepth();
}
```

## 3. 关键点解释

### 3.1 为什么这是「分类法」而非「画盒子」
盒子（VS 挤出的体）只是**让 FS 在「线可能覆盖的屏幕像素」里运行一次**的载体。真正决定颜色的是 §3 重建出来的**地形点**——它来自 `czm_globeDepthTexture`（地形/瓦片写入的真实深度），不是盒子自身的深度。于是：地形点离线足够近（§5/§7 通过）→ 上色；否则 → discard。这就是「把线刷在地形上」，且**不需要 stencil**、线宽随相机距离恒定（§4）。

### 3.2 对齐平面（§8）的作用
start/end 斜接平面在拐角处是倾斜的，直接用它们算 `distanceFromStart/End` 会让沿线纹理坐标 `s` 在拐角畸变。`alignedPlaneNormal = normalize(cross(cross(right, miterPlane), right))` 把斜接平面「掰正」到与右平面垂直、更朝向线方向，得到无畸变的沿线距离。纯色不需要 s/t，但保留计算以便 doc 09 扩展虚线/箭头/渐变。

### 3.3 `s` 的全线归一
`s = local_s · texNormX + texNormY`：`local_s∈[0,1]` 是段内归一，`texNormX=段长/全线长`、`texNormY=段起点累计/全线长`（doc 04 打包），故 `s` 是**整条线 [0,1]** 的弧长参数——虚线 pattern、渐变都基于它。

## 4. 材质路径 `lineMaterial(st)`（`#ifndef PER_INSTANCE_COLOR`，完整非占位）

本项目默认走 `PER_INSTANCE_COLOR`（纯色）。材质路径作为完整可选实现，支持**虚线**与**纵向渐变**，由 uniform 驱动：

```glsl
// FS prefix（doc 07）补充材质 uniform：
// uniform float u_lineDashEnabled;     // 0/1
// uniform float u_lineDashLengthMeters;// 实线段长（米）
// uniform float u_lineGapLengthMeters; // 间隙长（米）
// uniform float u_lineTotalMeters;     // 全线长度（米，构造期算）
// uniform vec4  u_color;               // 已在 prefix

vec4 lineMaterial(vec2 st) {
  vec4 col = u_color;
  if (u_lineDashEnabled > 0.5) {
    float along = st.x * u_lineTotalMeters;                 // 沿线米
    float period = u_lineDashLengthMeters + u_lineGapLengthMeters;
    float phase = mod(along, period);
    if (phase > u_lineDashLengthMeters) discard;            // 落在间隙 → 丢弃
  }
  return col;
}
```

> 虚线在 FS 按沿线米相位裁切，间隙处 discard。`u_lineTotalMeters` 在构造期由 doc 04 的 `length3D` 提供。这是完整实现，非占位；不启用虚线时 `u_lineDashEnabled=0`，等价纯色。

## 6. 边界与精度

1. **天空丢弃（§2）**：`depth==0` 即无地形写入处，必须 discard，否则线在天空背景上糊一片。
2. **depth-clamp/log-depth 配对**：FS 末尾 `czm_writeLogDepth()` 必须与 VS `czm_vertexLogDepth()` 成对、`LOG_DEPTH` define 一致；漏配近地闪烁（README 症结）。**注意**：移植自 Cesium 的原 FS 末尾是 `czm_writeDepthClamp()`；本项目走 LOG_DEPTH 路径，应改为 `czm_writeLogDepth()`（与 color/stencil 材质统一），且 VS 用 `czm_vertexLogDepth()`（非 `czm_depthClamp` 的 `v_WindowZ` 路径）。
3. **预乘 alpha（§10）**：`col.rgb *= col.a` 配合 doc 07 `blendSrc=ONE, blendDst=ONE_MINUS_SRC_ALPHA`；漏乘会过曝（README 症结）。
4. **DEBUG_SHOW_VOLUME**：保留 define，调试时把盒子染红半透，定位「线为何不出现」（多半是 depth 源未就绪或被天空 discard）。
5. **viewport UV**：`gl_FragCoord.xy / czm_viewport.zw` 中 `czm_viewport=(0,0,w,h)`（物理像素），与 `updateFrameStateUniforms` 写入一致；HiDPI 下 w/h 是 drawingBuffer 尺寸。
6. **metersPerPixel 的 pixelRatio**：§4/§5 的 `czm_metersPerPixel(eyeCoordinate)` 内部乘 `czm_pixelRatio`，HiDPI 必须设对（doc 08），否则 Retina 线宽差 2×。
