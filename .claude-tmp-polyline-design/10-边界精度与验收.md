## 2. 数值精度要点

1. **CPU 几何用 Float64**：ECEF 全程 Three `Vector3`（JS number=Float64），仅装配 `position3DHigh/Low` 时经 RTE 落 Float32。与 polygon 路径一致。
2. **RTE 双精度补偿**：`startBottom` 经 `encodeScalarRTE` 拆 high/low，VS `czm_translateRelativeToEye` 重组，消除高 zoom 抖动。
3. **forwardOffset 用 Float32**：段向量（通常 < 数百 km）单精度足够；它是相对量，不引入绝对位置抖动。
4. **Vincenty 收敛**：`|λ-λDot| ≤ EPSILON12`，与 Cesium 同阈值，保证 surfaceDistance 与加密点位置对拍 < 1e-6 相对误差。
5. **法线全程归一**：CPU 端 `breakMiter` 的 dot 判据依赖单位法线；GPU 端 `czm_normal*` 后 FS 仍用归一平面法线算距离。
6. **预乘 alpha 一致性**：FS `col.rgb*=col.a` ↔ 材质 `blendSrc=ONE`；任一缺失即过曝/发暗。

## 3. 校验规则（构造期 `resolvePublicLineOptions`）

- `points.length ≥ 2`，元素为 `[lon∈[-180,180], lat∈[-90,90]]`（度）。
- `strokeOpacity ∈ [0,100]`；`widthPixels > 0`（screen）/ `widthMeters > 0`（world）。
- `granularityRadians > 0`；`maximumHeight > minimumHeight`（否则 `max=min+1`）。
- `loop && points.length===2 → loop=false`。
- `arcType ∈ {'none','geodesic','rhumb'}`，`'rhumb'` 且类未就绪 → 构造期即抛（不延迟到渲染）。
- 违反 → `GeoForgeError('LINE_OPTIONS_INVALID', '<具体字段与原因>')`，绝不静默纠正后继续。

## 4. Spector.js / 帧抓取验证

抓取一帧，确认贴地线 draw call：

1. **无任何 `gl.stencilFunc / gl.stencilOp / gl.stencilMask` 调用**（线不碰模板）——与 polygon 的 3 个 stencil-related call 对比，线只有 1 个 color draw。
2. **混合状态** = `blendFunc(ONE, ONE_MINUS_SRC_ALPHA)`、`blendEquation(FUNC_ADD)`（预乘）。
3. **深度状态** = `DEPTH_TEST` 关、`depthMask(false)`。
4. **剔除** = `CULL_FACE` 开、`cullFace(FRONT)`（BackSide → 剔正面）。
5. **采样** = FS 采样 `czm_globeDepthTexture`（纹理单元绑定全局深度纹理）。
6. **面图元零回归**：重构 `createSharedUniforms` 后，polygon/circle/text 各抓一帧，uniform 集合/值/draw 序列与重构前字节级一致。

## 5. 视觉验收标准

| 项 | 标准 |
|---|---|
| 贴地 | 线随地形起伏精确贴合：**山脊不漏、谷底不浮**；无瓦片时贴椭球面 |
| 恒宽 | 相机从近到远缩放，屏宽模式下线宽**像素恒定**（不随距离变细/消失） |
| 拐角 | 折线拐角连续无缺口、无重叠暗边；尖角 `breakMiter` 后无暴长三角 |
| loop | 闭合环首尾平滑相接，无断口 |
| 转视角 | 旋转/俯仰不漂移、不闪烁（log-depth/depth-clamp 生效） |
| IDL | 跨 ±180° 折线正确连续，无横贯屏幕的错误长边 |
| 压面 | renderOrder=40 使线压在贴地面（30）之上 |
| 虚线 | 启用时实/隙按米恒定，沿线均匀（基于 length3D 的 s 参数） |
| 世界宽 | world 模式下线宽随缩放呈现真实米宽（远处变细） |

## 6. 性能验收

- **1000 条线**（各 ~10 折点，geodesic 加密）@ RTX 3060 / 1080p：**≥ 45 FPS**。
- 单 pass（仅 color draw），无 stencil pass；与 polygon（3 pass）相比单线开销更低。
- 几何构造在主线程一次性完成；`update` 每帧仅刷少量 uniform（矩阵 + 纹理引用），无每帧 CPU 重建几何。
- 内存：每段 8 顶点 ×(2 位置 vec3 + 5 vec4 + 1 batchId)，与 Cesium 同量级；`dispose` 释放 geometry/material，不释放共享深度纹理。
