# 贴地线设计 · 05 顶点着色器（VS）

> 移植 `Shaders/PolylineShadowVolumeVS.glsl` 到项目约定（GLSL ES 3.00 / RawShaderMaterial / RTE / log-depth / czm builtin），**删除全部 `COLUMBUS_VIEW_2D` 分支（项目 3D-only）**。VS 职责：把每段 box 的当前顶点在 eye space 内按屏幕像素宽度挤出，输出三平面（EC）+ 半宽 + 起止点给 FS。常量字符串 `POLYLINE_VS` 放 `materials.ts`，与现有 stencil/color shader 共用 `createVertexPrefix`。

---

## 1. 依赖的 prefix（`createVertexPrefix` 已提供，doc 07 再补两项）

`createVertexPrefix(defines)` 已注入：`czm_modelViewRelativeToEye`、`czm_normal`、`czm_encodedCameraPositionMCHigh/Low`、`czm_geometricToleranceOverMeter`、`czm_sceneMode`、`czm_currentFrustum`、log-depth uniforms、`#define czm_sceneMode3D 3.0`、`#define czm_computePosition() czm_translateRelativeToEye(position3DHigh, position3DLow)`、`czm_translateRelativeToEye`、`czm_branchFreeTernary`、`czm_depthClamp`、`LOG_DEPTH_VERTEX_HELPERS`（`czm_vertexLogDepth`）。

doc 07 在 VS prefix **补充**：`czm_metersPerPixel`（+其依赖 `czm_viewport`/`czm_frustumPlanes`/`#define czm_orthographicIn3D 0.0`/`uniform float czm_pixelRatio`）、**`uniform mat4 czm_projection`**（纯投影矩阵，每帧 Float64 写入）、`uniform float u_lineWidthPixels`、`#define GLOBE_MINIMUM_ALTITUDE 55000.0`，以及（可选材质）`u_lineWidthMode`/`u_lineWidthMeters`。

> 为何需要单独的 `czm_projection`：stencil 路径用 `czm_modelViewProjectionRelativeToEye` 一步到位；但贴地线必须**先在 EC 内挤出顶点、再投影**，所以 VS 要拿到 `positionEC` 后乘纯投影矩阵。`czm_modelViewRelativeToEye`（已有）给 EC，`czm_projection`（新增）给投影。两者都来自 `updateFrameStateUniforms` 的 Float64 计算（doc 08）。

## 2. `POLYLINE_VS` 全文（逐行注释）

```glsl
// ── 几何属性（doc 04 §9 契约）──
in vec3 position3DHigh;
in vec3 position3DLow;
in vec4 startHiAndForwardOffsetX;                       // xyz = RTE.high(startBottom), w = forwardOffset.x
in vec4 startLoAndForwardOffsetY;                       // xyz = RTE.low(startBottom),  w = forwardOffset.y
in vec4 startNormalAndForwardOffsetZ;                   // xyz = startPlaneNormal,       w = forwardOffset.z
in vec4 endNormalAndTextureCoordinateNormalizationX;    // xyz = endPlaneNormal,         w = texNorm3D.x · rightSide
in vec4 rightNormalAndTextureCoordinateNormalizationY;  // xyz = rightNormal,            w = texNorm3D.y · topBottomSide(/9.0)
in float batchId;                                       // 全 0 占位

// ── 输出到 FS ──
out vec4 v_startPlaneNormalEcAndHalfWidth;              // xyz = startPlaneEC.n, w = halfWidth(px)·0.5
out vec4 v_endPlaneNormalEcAndBatchId;                  // xyz = endPlaneEC.n,   w = batchId
out vec4 v_rightPlaneEC;                                // 右平面 (n, -dot(n,ecStart))
out vec4 v_endEcAndStartEcX;                            // xyz = ecEnd, w = ecStart.x
out vec4 v_texcoordNormalizationAndStartEcYZ;           // x=|texNormX|, y=texNormY(复原), zw=ecStart.yz

void main() {
  // 1) 段起点/终点/方向（EC）。RTE：startHi/Lo 经 translateRelativeToEye 得相对相机坐标
  vec3 ecStart = (czm_modelViewRelativeToEye *
      czm_translateRelativeToEye(startHiAndForwardOffsetX.xyz, startLoAndForwardOffsetY.xyz)).xyz;
  // 段向量在世界系是 forwardOffset，用 czm_normal（视图旋转 3x3）转 EC
  vec3 offset = czm_normal * vec3(startHiAndForwardOffsetX.w,
                                  startLoAndForwardOffsetY.w,
                                  startNormalAndForwardOffsetZ.w);
  vec3 ecEnd = ecStart + offset;
  vec3 forwardDirectionEC = normalize(offset);

  // 2) 三平面（EC，Hessian）。w = -dot(n, 平面上一点)
  vec4 startPlaneEC;
  startPlaneEC.xyz = czm_normal * startNormalAndForwardOffsetZ.xyz;
  startPlaneEC.w   = -dot(startPlaneEC.xyz, ecStart);
  vec4 endPlaneEC;
  endPlaneEC.xyz = czm_normal * endNormalAndTextureCoordinateNormalizationX.xyz;
  endPlaneEC.w   = -dot(endPlaneEC.xyz, ecEnd);
  v_rightPlaneEC.xyz = czm_normal * rightNormalAndTextureCoordinateNormalizationY.xyz;
  v_rightPlaneEC.w   = -dot(v_rightPlaneEC.xyz, ecStart);

  // 3) 透传 texcoord 归一与起止点（FS 算 s/t 用）
  v_texcoordNormalizationAndStartEcYZ.x = abs(endNormalAndTextureCoordinateNormalizationX.w);
  v_texcoordNormalizationAndStartEcYZ.y = rightNormalAndTextureCoordinateNormalizationY.w;
  v_endEcAndStartEcX.xyz = ecEnd;
  v_endEcAndStartEcX.w   = ecStart.x;
  v_texcoordNormalizationAndStartEcYZ.zw = ecStart.yz;

  // 4) 当前顶点 EC（box 8 角之一）
  vec4 positionRelativeToEye = czm_computePosition();          // translateRelativeToEye(position3DHigh, Low)
  vec4 positionEC = czm_modelViewRelativeToEye * positionRelativeToEye;  // w = 1.0

  // 5) 选离当前顶点更近的「斜接平面」，叉乘出挤出法线 normalEC（保证朝右）
  float absStart = abs(czm_planeDistance(startPlaneEC, positionEC.xyz));
  float absEnd   = abs(czm_planeDistance(endPlaneEC,   positionEC.xyz));
  vec3 planeDirection = czm_branchFreeTernary(absStart < absEnd, startPlaneEC.xyz, endPlaneEC.xyz);
  vec3 upOrDown = normalize(cross(v_rightPlaneEC.xyz, planeDirection)); // 起点平面处指上、终点处指下
  vec3 normalEC = normalize(cross(planeDirection, upOrDown));           // 横向挤出方向

  // 6) 底部顶点向下延伸（远视距覆盖地形起伏，与 GroundPrimitive 同理）。3D-only：sceneMode 恒 3D
  upOrDown = cross(forwardDirectionEC, normalEC);
  upOrDown = float(v_texcoordNormalizationAndStartEcYZ.y > 1.0
                || v_texcoordNormalizationAndStartEcYZ.y < 0.0) * upOrDown;   // 仅下沿顶点
  upOrDown = min(GLOBE_MINIMUM_ALTITUDE,
                 czm_geometricToleranceOverMeter * length(positionRelativeToEye.xyz)) * upOrDown;
  positionEC.xyz += upOrDown;
  // 复原 texNormY：>1.0 的哨兵(9.0) 还原为 0.0，其余取绝对值
  v_texcoordNormalizationAndStartEcYZ.y =
      czm_branchFreeTernary(v_texcoordNormalizationAndStartEcYZ.y > 1.0,
                            0.0, abs(v_texcoordNormalizationAndStartEcYZ.y));

  // 7) 半宽（像素）透传给 FS（FS 再乘 metersPerPixel 得世界半宽）
  float width = u_lineWidthPixels;
  v_startPlaneNormalEcAndHalfWidth.xyz = startPlaneEC.xyz;
  v_startPlaneNormalEcAndHalfWidth.w   = width * 0.5;
  v_endPlaneNormalEcAndBatchId.xyz = endPlaneEC.xyz;
  v_endPlaneNormalEcAndBatchId.w   = batchId;

  // 8) 屏幕空间挤出：把像素宽换算成当前 EC 处的米，再换算成沿 normalEC 的推进距离
  width = width * max(0.0, czm_metersPerPixel(positionEC));   // px → m（屏宽模式）
  width = width / dot(normalEC, v_rightPlaneEC.xyz);          // 沿 normalEC 的距离（斜接补偿）
  normalEC *= sign(endNormalAndTextureCoordinateNormalizationX.w);  // 左(-)/右(+)
  positionEC.xyz += width * normalEC;

  // 9) 投影 + depth-clamp + log-depth
  gl_Position = czm_depthClamp(czm_projection * positionEC);
  czm_vertexLogDepth();
}
```

## 3. 关键点解释（为何这样写）

- **§1/§2 RTE**：`startHi/Lo` 经 `czm_translateRelativeToEye` 得到相对相机的高精度位置，避免高 zoom 抖动；段向量 `forwardOffset` 是 Float32（段长通常 < 数百 km，单精度足够），用 `czm_normal` 旋到 EC。
- **§5 normalEC 推导**：盒子顶点处选「更近的斜接平面」，其法线与右平面法线叉乘得 `upOrDown`，再叉一次得到「与该平面对齐、朝右」的横向方向。拐角处两段共享顶点时，这保证挤出方向沿斜接对称轴，宽度连续。
- **§6 底部延伸**：只有「下沿顶点」（texNormY 越界哨兵标记）按 `czm_geometricToleranceOverMeter·视距` 向下延伸（上限 `GLOBE_MINIMUM_ALTITUDE`）。这让盒子在远视距足够「深」，覆盖相机看到的地形深度范围，与 polygon 的 EXTRUDED 分支共用同一套视距驱动逻辑。`czm_geometricToleranceOverMeter` 由 `updateFrameStateUniforms` 按 `pixelSizePerMeter·maximumScreenSpaceError` 算出（doc 08，已有）。
- **§8 屏宽换算**：`czm_metersPerPixel(positionEC)` 给出该 EC 深度下 1 像素对应的米；乘半宽像素得世界半宽。`/ dot(normalEC, rightPlaneEC.xyz)` 把「沿右平面法线的宽度」换算成「沿实际挤出方向 normalEC 的距离」（斜接处 normalEC≠rightNormal）。`sign(...w)` 决定该顶点往左还是往右挤。
- **§9 depth-clamp / log-depth**：`czm_depthClamp` 处理盒子穿越近/远平面的裁剪（emulate GL_DEPTH_CLAMP）；`czm_vertexLogDepth()` 写 `v_depthFromNearPlusOne` 供 FS `czm_writeLogDepth`。两者与项目 stencil 路径同协议，**必须与 FS 配对**（doc 06），否则近地闪烁（README 已记载该症结）。

## 4. 世界宽模式（`widthMode === 'world'`，非简化的完整分支）

公开 API 提供 `widthMode: 'screen' | 'world'`（doc 09）。VS 在 §7/§8 按 `u_lineWidthMode` 分发，两种都实现：

```glsl
// §7 半宽：屏宽存像素半宽，世界宽存米半宽（FS 据 u_lineWidthMode 解释）
float halfWidth = czm_branchFreeTernary(u_lineWidthMode > 0.5,
                    u_lineWidthMeters * 0.5,        // world：米
                    u_lineWidthPixels * 0.5);       // screen：像素
v_startPlaneNormalEcAndHalfWidth.w = halfWidth;

// §8 挤出距离：屏宽乘 metersPerPixel，世界宽直接用米
float pushMeters = czm_branchFreeTernary(u_lineWidthMode > 0.5,
                    u_lineWidthMeters * 0.5,
                    u_lineWidthPixels * max(0.0, czm_metersPerPixel(positionEC)) * 0.5);
pushMeters = pushMeters / dot(normalEC, v_rightPlaneEC.xyz);
normalEC *= sign(endNormalAndTextureCoordinateNormalizationX.w);
positionEC.xyz += pushMeters * normalEC;
```

FS 侧对应：`halfMaxWidth = (u_lineWidthMode>0.5) ? halfWidth : halfWidth·czm_metersPerPixel(eye)`（doc 06 §4）。**两模式同时实现、运行时切换，不留 TODO。**
