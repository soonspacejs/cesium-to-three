## 1. 为什么贴地线 ≠ 贴地面（必须读）

项目当前所有贴地图元（polygon / rectangle / circle / text / arrow）走 **GPU Z-fail Stencil Shadow Volume**：构建挤出棱柱，经 `stencilMesh`(DoubleSide，写 stencil)→ `colorMesh`(BackSide，按 stencil≠0 着色并清零) 两步把图元「灌」到地形上。该机制由共享类 `CesiumClassificationPrimitive`（front-stencil / back-stencil / color 三个 mesh）承载，是项目的「金标准」。

**贴地线不走这套机制。** Cesium 的 `GroundPolylinePrimitive` 用的是另一套独立技术——**深度纹理重建分类法（depth-reconstruction classification）**：

```
逐段构建一个“线描述 box”
  → VS：按屏幕像素宽度把 box 顶点动态挤出
  → FS：采样全局地形深度纹理，重建当前像素下的地形点(EC)
        算地形点到线的 right/start/end 三平面的距离
        |横向距离| > 半宽 或 越过端面 → discard，否则上色
```

两者本质区别：

| 维度 | 贴地面（stencil shadow volume） | 贴地线（depth-reconstruction） |
|---|---|---|
| “像素属于图元”的判据 | GPU 模板缓冲对前/后面穿越计数 | FS 内**重建地形点**，算到线三平面的解析距离 |
| 线宽语义 | 世界米（由几何固定） | **屏幕像素恒定**（`halfWidth × czm_metersPerPixel`），缩放不消失 |
| 渲染 Pass 数 | 3（front-stencil / back-stencil / color） | **1**（仅 color） |
| 模板缓冲 | 必需 | **不使用** |
| 几何 | 整块棱柱 | 每段 8 顶点 box，VS 运行时按屏宽挤出 |
| 承载类 | `CesiumClassificationPrimitive`（3 mesh） | **新增** `CesiumGroundPolylinePrimitive`（1 mesh） |

**为什么不能用面方案画线？** 若把线 buffer 成「米宽 corridor」再走 stencil：相机拉远时米宽对应亚像素，抗锯齿/采样会吃掉整条线；要恒定屏宽就得每帧 CPU 重建 corridor 几何，1000 条线下不可接受。Cesium 正因如此为线单设一条管线。**本套件即设计这条与 stencil 管线平行、仅复用下层基础设施的单 pass 管线。**

## 2. 整体数据流

```
CesiumGroundPolylineOptions (lon/lat 折线 + 屏宽 + 颜色 + arcType + loop)
        │  构造期（一次）
        ▼
┌─────────────────────────── CPU 几何（doc 02-04）───────────────────────────┐
│ 02 预处理：归一/去重 → 本初子午线+IDL 拆段 → cartographic 化 → arc 加密      │
│            产出 bottom[]、top[]、cartographic[]（沿地表密集点）              │
│ 03 法线：  逐顶点几何法线（miter / right-normal / breakMiter）→ normals[]    │
│ 04 段 Box：每段 8 顶点 + 36 索引；平面法线/forwardOffset/texcoord 打包；      │
│            adjustHeights + nudge；位置 RTE 编码 → BufferGeometry            │
└────────────────────────────────────────────────────────────────────────────┘
        │  → Three BufferGeometry（属性契约见 doc 04 §attribute 表）
        ▼
┌─────────── 渲染（doc 05-08）每帧 ───────────┐
│ 08 update：updateFrameStateUniforms 写每帧   │
│            相机 RTE / Float64 MVP / czm_projection / 深度纹理 /             │
│            log-depth / czm_metersPerPixel 依赖量                            │
│ 05 VS：    EC 内按屏宽挤出 box → czm_depthClamp → czm_vertexLogDepth        │
│ 06 FS：    采样 czm_globeDepthTexture 重建地形点 → 三平面距离判定 →         │
│            上色（premultiplied）→ czm_writeLogDepth                         │
│ 07 材质：  单 mesh、BackSide、depthTest/Write off、无 stencil、预乘混合      │
└──────────────────────────────────────────────────────────────────────────┘
        │  与 polygon 共用同一份全局地形深度纹理（depth.ts::CesiumGlobeDepth）
        ▼
   红线精确刷在地形/椭球面上，缩放恒宽、转视角不漂
```

依赖的**全局地形深度纹理**由 `depth.ts::CesiumGlobeDepth` + `createPackDepthMaterial` 产出（polygon 描边已在用），贴地线零改动复用：无 tiles 时由 `EllipsoidDepthMesh` 兜底，证明算法独立于地形数据源。

### 与 polygon 的文件对应（便于类比实现）

| polygon 文件 | line 对应 | 关键差异 |
|---|---|---|
| `polygon-hierarchy.ts`（归一） | `line-preprocess.ts` | 线是开放/闭合折线，无洞；多了本初子午线+IDL 拆段 |
| `polygon-subdivide-line.ts`（弦细分） | `line-densify.ts` | 线走**真大地线/恒向线**（geodesic/rhumb），非弦中点投影 |
| `polygon-construct-extruded.ts`（造棱柱） | `line-segment-attributes.ts` | 线无 cap 三角化，仅逐段 8 顶点 box + 三平面描述符 |
| `polygon-shadow-volume.ts`（facade） | `line-shadow-volume.ts` | 属性多 5 个 vec4；无 `extrudeDirection`/`polygonRectangle` |
| `polygon-extents.ts`（planar uv） | 无 | 线宽在 FS 用平面距离解算，不需要 planar uv |

## 4. 分层归属（对齐 GIS-Forge L0~L6 精神）

| 层 | 贴地线组件 |
|---|---|
| L0 数学 | `math/ellipsoid-geodesic.ts`、`math/ellipsoid-rhumb-line.ts`、`math/rte-encoding.ts`（复用）、`math/ellipsoid.ts`（复用） |
| L1 GPU 资源 | 复用 `depth.ts::CesiumGlobeDepth`（全局地形深度纹理） |
| L2 渲染管线 | `materials.ts::createPolylineMaterial` + `POLYLINE_VS/FS`；每帧 uniform（`updateFrameStateUniforms`） |
| L5 几何/扩展 | `line/*`（几何构建器，正交于 stencil 管线） |
| L6 图元 | `primitives.ts::CesiumGroundPolylinePrimitive` |

> 设计原则：**底层共享，上层正交**。线复用 math / 深度源 / 每帧 uniform / czm builtin（下层），新增几何/shader/材质/图元（上层），绝不侵入已被 Spector.js 验证的 stencil 路径。

## 6. 对外契约（公开 API 形态，详见 doc 09）

```typescript
new CesiumGroundPolylinePrimitive({
  points: [[121.50,31.24],[121.51,31.25],[121.53,31.245]], // lon/lat
  strokeColor: '#ff3030',
  strokeOpacity: 95,           // 0..100 百分比（与其它图元一致）
  widthPixels: 3,              // 屏幕像素宽（默认 3）
  visible: true,
  loop: false,                 // 闭合
  arcType: 'geodesic',         // 'geodesic' | 'rhumb' | 'none'
  granularityRadians: Math.PI/180/32,
  minimumHeight: -55000, maximumHeight: 55000,  // 高级：覆盖默认窗口
  widthMode: 'screen',         // 'screen'(默认,像素恒定) | 'world'(米恒定)
  widthMeters: 5,              // widthMode==='world' 时使用
  renderOrder: 40,
});
// 对外方法：.group(Three.Group) / update(frameState) / setRenderOrder(n) /
//          setColor(color,opacity) / setWidth(px|m) / setVisible(b) / dispose()
```

每帧由宿主调用 `primitive.update(frameState)`，`frameState` 形如：

```typescript
interface CesiumGroundFrameState {
  depthTexture: Texture;  // 全局地形深度纹理（CesiumGlobeDepth 产出）
  width: number;          // drawingBuffer 物理像素宽
  height: number;
  camera: PerspectiveCamera;
  pixelRatio?: number;    // 【新增】renderer.getPixelRatio()，默认 1.0
}
```
